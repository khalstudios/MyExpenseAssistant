MyExpenseAssistant - Build, Test, and Run on Phone

There is one build of the app: the same APK goes on your phone, to testers
and (as an .aab) to Play.

Prerequisites
- Connect the Android phone through USB.
- Enable Developer options and USB debugging.
- Approve the RSA USB-debugging prompt on the phone.

1. Check that the phone is connected

& 'C:\Users\shard\AppData\Local\Android\Sdk\platform-tools\adb.exe' devices

The phone should appear with the status: device

2. Build the app and run unit tests

$gradle = "$env:LOCALAPPDATA\Gradle\gradle-8.9\bin\gradle.bat"

& $gradle :app:assembleDebug :app:testDebugUnitTest `
  --no-daemon `
  --no-configuration-cache `
  --console=plain

A successful run ends with:

BUILD SUCCESSFUL

Other tasks you may need:

  :app:assembleDebug        debug APK for your phone
  :app:testDebugUnitTest    unit tests
  :app:assembleRelease      signed APK for sideloading and testers
  :app:bundleRelease        Play upload bundle (.aab)
  :app:build                debug and release, plus lint and tests

3. Install/update the app on the phone

$adb = 'C:\Users\shard\AppData\Local\Android\Sdk\platform-tools\adb.exe'

& $adb install -r `
  'D:\My Projects\AI_Assisted\MyExpenseAssistant\app\build\outputs\apk\debug\app-debug.apk'

The -r flag updates the installed app while preserving transaction data and settings.

4. Relaunch the app

& $adb shell am force-stop com.khaltech.expenseassistant
& $adb shell am start -n com.khaltech.expenseassistant/.ui.MainActivity

5. Confirm the installed build

& $adb shell dumpsys package com.khaltech.expenseassistant |
  Select-String 'lastUpdateTime'

If this build changed the Room schema version, this is the run that proves
the migration works: -r keeps the existing database, so the app has to
migrate your real data on first launch. Open it and check your transactions
are still listed. A migration that throws crashes the app on startup.

APK locations

Debug build for your phone:
D:\My Projects\AI_Assisted\MyExpenseAssistant\app\build\outputs\apk\debug\app-debug.apk

Signed builds to share come from scripts/release.sh, which copies them to
the repo root as KahanGayaPaisa-release.apk (sideloading and testers)
and KahanGayaPaisa-release.aab (Play upload).

Anything under app\build\outputs\apk\direct\ or app\build\outputs\apk\play\,
and any MyExpenseAssistant-direct-*, MyExpenseAssistant-play-* or bare
MyExpenseAssistant.apk in the repo root, comes from the retired play/direct
builds. Those are stale - delete them rather than installing them.

Terminal note

If PowerShell corrupts the first token of a command, run this first and then retry:

Write-Output "start"
